# Mastery Orb experimental module

Archived from POC Anvil v3.8.7. This standalone experimental module preserves
the station, interaction, recovery, migration, recipes, and test functions from
the audited source. It is excluded from the Tool Mastery 3.8.8 pack.

See the [anvil persistence study](../../../docs/discovery/research/reports/anvil_behavior.md) for vanilla left-slot behavior. This POC experiments with a distinct 25% XP transfer.

The old POC implementation does not yet implement the 3.8.8 enchantment transfer
or the corrected orb identity. It is preserved as research code, not an approved
release. Debug and legacy user-facing text may be pt-BR.
